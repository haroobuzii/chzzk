# 로그인 상태는 DB의 세션과 HttpOnly 쿠키로 유지한다

로그인하면 서버가 긴 무작위 세션 값을 만들어 브라우저에 `HttpOnly` 쿠키로 주고, DB에는 그 값의 해시와 사용자, 만료 시각(7일 뒤)을 저장한다. 요청마다 쿠키의 값으로 DB의 세션을 찾아 사용자를 알아낸다. 로그아웃하면 DB의 세션을 지워 그 즉시 무효가 된다. 쿠키는 자바스크립트가 읽지 못하고, `SameSite=Lax`라서 다른 사이트에서 보낸 POST에는 실리지 않는다. 비밀번호는 Argon2 해시로만 저장한다.

화면과 서버가 같은 주소(내 컴퓨터, 또는 같은 터널 주소)에 있으므로 쿠키를 그대로 쓸 수 있다. 2단계의 송출 키와 같은 "무작위 값 + DB에는 해시" 방식이라 구현과 테스트 도구를 다시 쓴다.

## Considered Options

- **JWT**: 서버가 서명한 토큰을 브라우저가 들고 다녀 DB 조회가 줄지만, 로그아웃해도 토큰이 만료될 때까지 살아 있다. 무효로 만들려면 결국 차단 목록을 DB에 둬야 한다.

## 다른 출처 요청 막기(CSRF)는 Sec-Fetch-Site를 먼저 본다

상태를 바꾸는 요청은 다른 사이트에서 온 것인지 확인한다. 처음에는 `Origin`과 요청 주소(`Host`)를 비교하려 했지만, 개발 서버(`dx serve`)의 프록시가 `Host`를 바꿔 같은 출처 요청까지 거절되었다. 그래서 브라우저가 붙이고 웹 페이지가 지어낼 수 없는 `Sec-Fetch-Site`가 있으면 그 값이 `same-origin`일 때만 받는다. 없으면 `Origin`과 `Host`를 비교하고, 둘 다 없으면(curl, 테스트) 쿠키 규칙만 따른다. `SameSite=Lax` 쿠키와 함께 이중으로 막는다.
