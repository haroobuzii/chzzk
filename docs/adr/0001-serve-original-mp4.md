# 영상은 변환 없이 원본 MP4로 전송한다

등록할 때 MP4(H.264/AAC)만 받고, 서버는 원본 파일을 HTTP Range 요청으로 그대로 전송해 브라우저 `<video>`로 재생한다. HLS로 변환하면 어떤 포맷이든 받을 수 있고 화질도 고를 수 있지만, ffmpeg와 변환 대기열이 필요하고 방송에 "처리 중" 상태가 생긴다. 그러면 "방송은 언제나 재생 가능하다"는 모델이 깨진다. 업로드 시점에는 확장자와 `ftyp` 시그니처만 확인하고 코덱은 검사하지 않는다.

## Considered Options

- **HLS 변환**: 라이브 송출 단계에서 HLS나 WebRTC가 들어오면 다시 검토한다.
