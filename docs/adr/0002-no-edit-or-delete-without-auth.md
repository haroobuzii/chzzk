# 인증이 없으므로 방송 수정과 삭제를 제공하지 않는다

이번 단계에는 인증과 인가가 없어서 누구나 방송을 등록하고 시청한다. 여기에 수정이나 삭제를 열면 누구나 남의 방송을 바꾸거나 지울 수 있으므로 등록과 조회만 제공한다. 수정과 삭제는 소유자를 확인할 방법이 생긴 뒤에 추가한다.

## 3단계에서 바뀜

3단계에서 로그인과 방송 소유자가 생겼다. 그래서 소유자에게만 방송 수정(제목만)과 삭제를 연다. 삭제하면 방송 정보, 영상 파일, 그 방송의 댓글을 모두 지운다. 방송 번호는 다시 쓰지 않는다. 1·2단계에서 만든 방송은 소유자가 없으므로 지금도 누구도 수정·삭제할 수 없다.
