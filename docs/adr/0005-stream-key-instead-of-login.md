# 로그인 대신 송출 키로 라이브 방송의 송출과 종료를 지킨다

2단계에도 로그인이 없다. 그대로 두면 누구나 남의 라이브 방송을 끄거나, 같은 방송에 다른 영상을 끼워 보낼 수 있다. 그래서 라이브 방송을 시작하면 서버가 긴 무작위 송출 키를 만들어 시작한 화면에만 돌려주고, DB에는 키의 해시만 저장한다. 송출(MediaMTX가 우리 서버에 송출 허락을 묻는다)과 종료는 이 키가 맞을 때만 된다. 시청에는 키가 필요 없다.

키는 그 방송 하나에만 쓰는 열쇠라서 계정이나 로그인이 아니다. 3단계에서 로그인이 생기면 방송 소유자로 바꿀 수 있다.

송출 화면을 닫거나 연결이 끊겨 종료 요청이 오지 않을 수 있다. 그래서 MediaMTX에서 송출이 사라진 것을 서버가 알아채면 몇 초 안에 방송 상태를 종료로 바꾼다.
