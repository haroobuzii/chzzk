# 04: 방송 종료와 자동 종료

**What to build:** 송출자가 송출 화면의 "방송 종료"를 누르면 다음이 일어난다.

1. 종료 API(`POST /api/live/{번호}/end`, 송출 키 필요)를 부른다.
2. WebRTC 연결을 닫고 카메라와 마이크를 끈다.
3. 방송 상태가 종료가 되고 종료 시각이 남는다.
4. 서버는 MediaMTX의 송출 세션도 끊는다. 실패해도 무시한다.

송출 화면을 떠날 때(pagehide)도 `keepalive` 요청으로 종료를 시도한다. 그 요청이 오지 않아도 상태 감시기가 처리한다.

- MediaMTX에서 경로가 사라지면 방송 중 → 종료가 된다.
- 준비로 30초가 지나도록 영상이 없으면 버려진다.
- 서버가 켜질 때 바로 한 번 맞추므로, 꺼진 동안 끝난 방송도 종료가 된다.

상태는 스펙의 "상태 바꾸기"에 적힌 조건부 전환으로만 바뀌고, 되돌아가지 않는다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 종료 요청은 이렇게 응답한다.
  - 맞는 키면 204이고 종료가 되며 종료 시각이 생긴다
  - 틀린 키면 401이고 상태는 그대로다
  - 준비 중에 종료하면 버려진다
  - 두 번 종료해도 204다
- [ ] 감시 한 번 맞추기는 아래처럼 동작한다.
  - 경로가 사라지면 방송 중 → 종료
  - 준비로 30초가 지나면 버려짐(30초 전에는 그대로)
  - 종료된 방송은 경로가 다시 나타나도 방송 중이 되지 않는다
- [ ] 같은 DB에 새로 연결해도 라이브 방송의 상태와 시각이 그대로 조회된다
- [ ] 컴퓨터 브라우저에서 "방송 종료"와 탭 닫기로 각각 종료되는 것을 직접 확인한다
