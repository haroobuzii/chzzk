# 05: 송출 화면 다듬기

**What to build:** 휴대폰 송출자가 막힘 없이 방송하도록 송출 화면을 다듬는다.

- 전면·후면 카메라 전환 버튼을 둔다. 방송 중에는 보내는 트랙만 바꿔 끼워 송출이 끊기지 않는다.
- 송출하는 동안 Screen Wake Lock으로 화면 꺼짐을 막는다. 지원하지 않으면 "송출 중에는 화면을 켜 두세요"를 보여 준다.
- 다음 경우마다 한국어 안내를 보여 준다.
  - 카메라·마이크 권한 거절: 다시 허용하는 방법
  - HTTPS가 아닌 주소: 터널의 HTTPS 주소로 접속하라는 안내
  - 송출 연결 실패: 같은 와이파이인지 확인하라는 안내와 다시 시도
- 연결 중에는 "연결하는 중…"을 보여 주고 시작 버튼을 막는다.
- 방송 중에는 상세 화면 링크를 보여 주고, 복사 버튼을 둔다.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 방송 중에 카메라를 바꿔도 시청 화면의 영상이 끊기지 않고 바뀐다(컴퓨터에서 가짜 장치 두 개나 직접 확인)
- [ ] Wake Lock을 지원하면 걸고, 종료하면 푼다. 지원하지 않으면 안내가 보인다
- [ ] 권한 거절, HTTPS 아님, 연결 실패마다 다른 한국어 안내가 보인다
- [ ] 연결 중에는 시작 버튼이 다시 눌리지 않는다
- [ ] 방송 중에 상세 화면 링크가 보이고 복사된다
