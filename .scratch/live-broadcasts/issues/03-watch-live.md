# 03: 라이브 시청과 목록 표시

**What to build:** 시청자가 첫 화면 맨 위 "지금 라이브" 칸에서 방송 중인 방송을 보고, 카드를 누르면 상세 화면(`/broadcasts/{번호}`)에서 실시간으로 시청한다. 방송 중인 방송이 없으면 이 칸은 숨긴다. 시청은 우리 서버를 거친 WebRTC(WHEP)로 하며, 키는 필요 없다.

- **목록**
  - 아래 전체 목록은 녹화·라이브를 함께 최신순으로 보여 준다. 정렬 기준은 녹화는 등록 시각, 라이브는 시작 시각이다.
  - 카드 표시와 시각은 아래와 같다.
    - 녹화: 녹화 표시와 등록 시각
    - 방송 중: 빨간 LIVE 표시와 시작 시각
    - 종료: 종료 표시와 시작 시각
  - 5초마다 갱신한다.
- **상세의 방송 중 화면**
  - `<video autoplay muted playsinline>`에 영상을 띄우고 "소리 켜기" 버튼을 둔다.
  - 5초마다 상태를 확인하고, 종료되면 연결을 닫고 "방송이 종료되었습니다"를 보여 준다.
- **상세의 종료 화면**: 시작 시각과 방송한 시간(예: 12분 34초)을 보여 준다. 다시 볼 수 없다는 것도 알 수 있다.

계약은 스펙의 `POST /api/live/{번호}/whep`과 세션 PATCH·DELETE를 따른다.
