# 03: 실패·취소·만료

**What to build:** 결제가 실패하거나 결제창을 닫으면 토스가 `/donations/fail?code&message&orderId`로 돌려보낸다.

- 결과 화면은 `POST /api/donations/fail`을 부르고 안내를 보여 준다.
  - 취소 코드(`PAY_PROCESS_CANCELED`, `USER_CANCEL`): "결제를 취소했습니다"
  - 그 밖: 실패 이유
- 서버는 **로그인한 후원자 본인의 결제 대기 주문서만** 바꾼다. 취소 코드면 취소, 그 밖은 실패다. 주문 번호가 없거나 남의 주문서면 아무것도 바꾸지 않는다.
- 결제 대기로 **30분**이 지난 주문서는 만료가 된다.
  - 1분마다 도는 정리 작업이 바꾼다. "지금 시각"을 받는 한 번 정리 함수로 둔다.
  - 승인 확인도 만료된 주문서는 확정하지 않는다. 결과 화면은 "시간이 지나 결제가 취소되었어요"를 보여 준다.
- 실패·취소·만료 주문서는 합계·내역에 나오지 않는다. 결과 화면에는 테스트 결제 표시와 방송으로 돌아가는 링크가 있다.

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 후원자 본인이 실패 API를 부르면 이렇게 바뀐다. 취소 코드는 취소, 다른 코드는 실패이고, 합계·내역은 그대로다
- [x] 다른 사용자나 비로그인이 부르면 주문서가 바뀌지 않는다. 주문 번호가 없으면 204다
- [x] 한 번 정리하면 30분이 지난 결제 대기만 만료되고, 30분 전은 그대로다
- [x] 만료된 주문서로 확인 요청이 오면 확정되지 않고, 가짜 토스에 승인 요청도 가지 않는다
- [x] 확정·실패·취소·만료는 서로 바뀌지 않는다(조건부 전환)
- [x] 실패·취소·만료 안내 화면을 브라우저로 확인한다(결과 주소를 직접 열어)
