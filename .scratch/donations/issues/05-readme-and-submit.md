- 4단계 범위, 범위 밖과 한계
  - 실제 결제, 환불, 정산, 계좌이체·휴대폰·가상계좌, 결제위젯
- 테스트 모드라 돈이 나가지 않는다는 안내와 테스트 키 강제
- 토스페이먼츠 개발자센터에서 테스트 키(`test_ck_`/`test_sk_`) 받는 법과 `.env` 예시(자리표시자)

- 확인 절차

  - **취소**: 결제창을 닫는다.
  - **금액 조작 거절**: 돌아온 주소의 `amount`를 바꿔 다시 연다.
  - **승인 통지 중복**: 확정된 결제의 결제 키로 `curl` 통지를 두 번 보내고, 합계가 한 번만 늘었는지 본다.
  - (선택) 터널 주소를 개발자센터 웹훅에 등록해 진짜 통지를 받는다.
- 새 환경변수 표, HTTP 라우트, 파일 위치, 테스트 묶음과 실제 결과
