# 치지직 만들기 ⑤ 로컬 오토스케일

마감: 12/12 (토) 23:59

## 목표

앞 단계까지 만든 치지직 서비스를 로컬 환경에서 여러 인스턴스로 띄우고, 부하에 따라 인스턴스 수가 자동으로 늘고 줄게 만드세요.

## 구현 범위

- 서버를 컨테이너 이미지로 만들 수 있게 합니다.
- 로컬 클러스터나 오케스트레이터(kind·minikube·k3d·Docker Desktop Kubernetes·Docker Compose 등, 도구는 자유)에서 서버를 여러 인스턴스로 실행합니다.
- CPU 사용률·요청 수 같은 지표를 기준으로 최소·최대 인스턴스 수 안에서 자동으로 스케일 아웃·인 하게 합니다. Kubernetes HPA 같은 기본 기능을 써도 되고 직접 만든 스케일러도 됩니다.
- 여러 인스턴스 앞에서 요청을 나눠 받도록 합니다(Service, 리버스 프록시 등).
- 인스턴스가 늘거나 줄어도 로그인 세션·업로드한 영상·라이브 상태·댓글·도네이션이 유지되도록, 상태를 인스턴스 밖의 공용 저장소(DB, Redis, 공유 볼륨, 오브젝트 스토리지 등)에 둡니다.
- 부하를 발생시키는 스크립트나 설정을 함께 넣습니다(k6, hey, wrk, ab, 직접 만든 스크립트 등).
- 이번 단계에서는 클라우드 배포를 요구하지 않습니다.

## 직접 확인

부하를 걸었을 때 인스턴스 수가 늘어나고, 부하를 멈추면 다시 줄어드는지 확인하세요. 스케일이 바뀌는 동안에도 로그인 상태와 방송 목록·댓글이 그대로인지 확인하세요. 확인한 인스턴스 수 변화(명령 출력이나 캡처)를 README에 남겨 주세요.
