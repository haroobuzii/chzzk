# 치지직 만들기 ⑥ 도메인·OCI 배포와 Windows/macOS 클라이언트

주소: https://classroom.codemit.kr/classes/6/problems/(⑥) · 권장 기한: 11/22 (일) 23:59

## 목표

앞 단계에서 만든 방송 서비스의 백엔드를 OCI Always Free VM에 배포하고, 구매한 도메인으로 서비스에 접속할 수 있게 하세요. Windows와 macOS에서 실행되는 데스크톱 클라이언트를 빌드해 다운로드로 배포하세요.

## 구현 범위

- **도메인과 HTTPS** — 서비스에 사용할 도메인을 구매하세요. DNS를 OCI VM으로 연결하고, 백엔드와 다운로드 페이지를 HTTPS로 제공하세요. README에 도메인 등록 여부, 최초 등록 비용과 갱신 비용, 공개 주소와 DNS·TLS 구성 방법을 적으세요.
- **OCI Always Free VM** — 홈 리전의 가용성과 계정 잔여 한도를 확인한 뒤, Always Free 범위에서 서비스에 적합한 VM 한 대를 생성하세요. Oracle 공식 문서 기준 A1 가용 시 우선 후보는 ARM64 VM.Standard.A1.Flex 2 OCPU·12GB입니다. 이 용량은 계정 내 다른 A1 인스턴스가 무료 할당량을 쓰지 않을 때의 기준입니다. 재고나 리전 제한이 있으면 무료 대안과 선택 이유를 README에 남기세요.
- **백엔드** — 기존 방송·계정·댓글·후원 기능을 유지하고, 배포에 필요한 실행 설정과 상태 확인 경로를 추가하세요. 배포 환경의 서비스 주소와 비밀 값은 환경 설정으로 관리하세요.
- **데스크톱 클라이언트** — Windows와 macOS에서 실행 가능한 설치 파일 또는 실행 패키지를 만드세요. 클라이언트에서 배포한 백엔드의 방송 목록을 조회하고 재생할 수 있게 하세요. 다운로드 페이지에 OS별 파일 링크, 지원 아키텍처, 설치·실행 방법을 표시하세요. 구현 언어와 패키징 도구는 자유입니다.

## 직접 확인

외부 네트워크에서 도메인과 HTTPS, 클라이언트 다운로드를 확인하세요. Windows와 macOS에서 각각 공개 링크로 패키지를 내려받아 설치 또는 실행하고, 방송 목록 조회와 재생을 확인하세요. README에 테스트한 OS·아키텍처와 각 결과를 남기세요.

## 제출

소스 파일·ZIP 또는 GitHub 저장소 주소를 제출하세요. 서버 배포 설정, 클라이언트 빌드·패키징 설정, 다운로드 페이지 소스 또는 배포 설정, 공개 주소와 재현 절차를 포함하세요. 실제 비밀 값과 결제정보는 제출물에서 제외하세요.

참고: Oracle Cloud Always Free 리소스 https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm
