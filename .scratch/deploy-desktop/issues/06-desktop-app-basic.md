# 06: 데스크톱 앱 기본(목록·녹화 재생·웹에서 열기)

**What to build:** 맥에서 앱 "녹화방송"을 열면 배포 서버(또는 빌드 때 정한 서버)의 방송 목록이 보이고, 녹화 방송을 재생하고, "웹에서 열기"로 기본 브라우저에 같은 방송 페이지를 연다.

- 같은 크레이트에 앱용 기능을 더한다. 서버 기능 없이 데스크톱으로 빌드된다. 번들 ID `com.haroobuzii.chzzk`.
- 서버 주소는 빌드 때 정한다(기본 `https://chzzk.haroobuzii.com`, 개발 땐 로컬 주소).
- **서버 연결 모듈**(테스트 대상)
  - 방송 목록·단건을 Rust HTTP로 받아 JSON을 읽는다.
  - 녹화 영상 절대 주소, WHEP 주소, 웹 방송 페이지 주소를 서버 주소 기준으로 만든다.
  - 서버가 꺼졌거나 오류면 "서버에 연결할 수 없어요" 같은 사용자 문구로 바꾼다.
- 화면: "지금 라이브" 칸, 녹화·LIVE·종료 표시, 소유자 아이디, 시각. 라이브 상태 5초 갱신. 연결 실패 시 "다시 시도". 웹 화면 컴포넌트를 최대한 재사용한다.
- 녹화 재생은 `<video>`에 절대 주소, 중간 건너뛰기 가능.
- 앱에는 로그인·댓글·후원 입력이 없고 "웹에서 열기"만 있다(ADR 0009).
