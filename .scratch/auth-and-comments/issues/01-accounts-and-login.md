# 01: 회원가입·로그인·로그아웃

**What to build:** 방문자가 `/signup`에서 아이디와 비밀번호로 회원가입하면 바로 로그인된다. `/login`에서 로그인하고, 머리글의 "로그아웃"으로 로그아웃한다. 머리글은 로그인 전에는 "로그인", 후에는 "아이디님"과 "로그아웃"을 보여 준다. 로그인 화면은 `next`로 받은 이 서비스 안의 주소(`/`로 시작하고 `//`로 시작하지 않음)로 돌아간다.

스펙의 "계정", "현재 사용자 확인", "쿠키와 CSRF", HTTP 계약의 `/api/auth/*`를 따른다. 사용자·세션 표를 새 마이그레이션으로 만들고, 로그인 상태는 서버 세션과 쿠키로 둔다(ADR 0006). 모든 권한 검사가 쓸 "현재 사용자" axum 추출기와, 401/403 실패 응답, 상태 변경 요청의 `Origin` 확인을 이 티켓에서 만든다. 테스트 손님 셋(쿠키 없는 비로그인, 가입·로그인 API로 쿠키를 받은 사용자 A·B)을 만드는 공용 테스트 도우미도 만든다. 02~05가 이것을 쓴다.

새 마이그레이션 파일 이름은 번호 대신 `YYYYMMDDHHMMSS_` 날짜·시각으로 시작한다. 병렬 티켓끼리 번호가 겹치지 않게 하기 위해서다.

**Blocked by:** None (can start immediately)
