# 05: 댓글

**What to build:** 녹화 방송과 라이브 방송의 상세 화면 아래에 댓글 칸을 둔다.

- 누구나 댓글 목록을 오래된 순으로 본다. 작성자 아이디와 쓴 시각(한국 시간)이 함께 나온다.
- 로그인한 사용자는 1~300자 댓글을 쓴다. 앞뒤 공백은 지운다.
- 로그인하지 않았으면 입력 칸 대신 "로그인하고 댓글을 남겨 보세요"와 로그인 링크를 보여 준다.
- 내 댓글에는 "삭제"가 붙는다. 수정은 없다.
- 방송 중인 라이브 방송에서는 댓글 목록을 3초마다 다시 불러온다.
- 종료된 라이브 방송에도 댓글을 쓸 수 있다.

계약은 스펙의 `GET`·`POST /api/broadcasts/{번호}/comments`, `DELETE /api/comments/{댓글 번호}`를 따른다. 댓글 표는 날짜·시각 이름 마이그레이션으로 만들고, 방송이 지워지면 댓글도 지워지게 한다(ON DELETE CASCADE). 04의 삭제가 이것에 기댄다.

- [x] 빈 댓글, 공백뿐인 댓글, 301자 댓글은 400이다. 없는 방송에 쓰면 404다

- [x] 댓글 삭제는 이렇게 응답한다. 작성자는 204, 다른 사용자는 403(댓글이 그대로), 비로그인은 401, 없는 댓글은 404
