# 02: 등록·라이브 시작에 로그인과 소유자

**What to build:** 녹화 방송 등록(`POST /api/broadcasts`)과 라이브 방송 시작(`POST /api/live`)에 로그인이 필요해진다. 로그인하지 않으면 서버가 401로 거절한다. 화면에서는 "녹화 올리기"와 "라이브 시작"을 누르거나 그 주소로 들어오면 로그인 화면(`/login?next=…`)으로 보낸다. 로그인한 사용자가 만든 방송에는 그 사용자가 소유자로 기록된다.

목록 카드와 상세 화면에는 소유자 아이디가 보이고, 1·2단계 방송은 "익명"으로 보인다. 목록·상세 조회 결과에 소유자 아이디를 더한다. 방송 표에 소유자 칸을 더하는 마이그레이션을 날짜·시각 이름으로 만든다.

1·2단계 테스트는 각 테스트의 본문을 바꾸지 않는다. 등록 요청과 라이브 시작을 만드는 **공용 도우미에서만** 로그인한 사용자 쿠키를 붙인다(CODING_STANDARDS.md의 예외). 송출 키는 이 티켓에서 그대로 둔다. 03이 바꾼다.

- [ ] 비로그인 등록과 비로그인 라이브 시작은 401이다. 방송도, 보관 폴더의 파일도 남지 않는다
- [ ] 로그인한 사용자가 만든 녹화·라이브 방송의 소유자가 그 사용자다(목록·상세 조회로 확인)
- [ ] 기존 방송은 소유자 없음으로 조회된다(마이그레이션 뒤에도 1·2단계 행이 그대로)
- [ ] 목록 카드와 상세 화면에 소유자 아이디 또는 "익명"이 보인다
- [ ] 로그인하지 않고 `/new`, `/live/new`에 들어가면 로그인 화면으로 가고, 로그인 뒤 원래 화면으로 돌아온다(브라우저로 직접 확인)
