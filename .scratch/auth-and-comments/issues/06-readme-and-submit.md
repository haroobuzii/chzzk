# 06: README와 step-3 제출 준비

**What to build:** 채점자가 README만 읽고 3단계를 이해하고 따라 할 수 있게 한다. 1·2단계 내용은 유지하고 아래를 더한다.

- 3단계 구현 범위, 범위 밖, 한계(로그인 시도 횟수 제한 없음)
- 공개 범위 표: 비로그인·로그인·소유자·작성자가 각각 할 수 있는 일
- 로그인 방식 요약(서버 세션과 쿠키, 7일, 로그아웃하면 바로 무효, 비밀번호는 해시만 저장)과 ADR 0006 링크
- 직접 확인 절차
  - 일반 창(사용자 A), 시크릿 창(사용자 B), 또 다른 시크릿 창(비로그인)을 연다
  - 등록, 라이브 시작, 제목 수정, 삭제, 송출·종료, 댓글 쓰기, 댓글 삭제의 허용과 거절을 본다
- 화면을 거치지 않는 요청으로 거절을 확인하는 `curl` 예시. 예: B의 쿠키로 A의 방송 삭제 → 403, 쿠키 없이 댓글 쓰기 → 401
- 휴대폰(터널 주소)과 컴퓨터(localhost)는 로그인을 따로 해야 한다는 안내
- 테스트 실행 방법과 실제 결과

1·2단계와 같은 공개 저장소에 올리고 `step-3` 태그를 붙인다. 공개 저장소에 올리는 일은 사용자에게 먼저 확인한다. 실제 비밀 값은 넣지 않는다.
