# 03: 송출 제어를 소유자 확인으로

**What to build:** 라이브 방송의 송출과 종료를 송출 키 대신 "로그인한 소유자"로 지킨다(ADR 0005의 3단계 변경). 아래 요청은 비로그인이면 401, 소유자가 아니면 403이다. 거절된 송출 연결 요청은 MediaMTX로 넘어가지 않는다.

- 송출 연결: `POST /api/live/{번호}/whip`과 세션 `PATCH`·`DELETE`
- 종료: `POST /api/live/{번호}/end`

정리할 것은 아래와 같다.

- 라이브 시작 응답에서 송출 키를 없앤다.
- 송출 키 해시 칸과 그것을 요구하던 `CHECK`를 날짜·시각 이름 마이그레이션으로 없앤다.
- 송출 화면의 키 처리 코드를 지운다. 같은 출처 요청이라 쿠키가 실리므로 시작, 카메라 전환, 종료, 화면을 떠날 때 keepalive 종료는 그대로 동작해야 한다.

상세 화면에는 소유자에게만, 방송 중일 때 "방송 종료" 버튼이 보인다. 그래서 송출 화면을 닫았어도 소유자가 끌 수 있다.

송출 키를 직접 확인하던 2단계 테스트(키 해시 저장, 틀린 키 401)는 같은 의미의 소유자 테스트(비로그인 401, 다른 사용자 403)로 바꾸고, 커밋 메시지에 적는다. 2단계의 나머지 테스트 본문은 그대로 두고 공용 도우미만 소유자 쿠키를 쓰게 한다.

  - 비로그인은 401
  - 다른 사용자는 403
  - 소유자는 성공
- [x] 라이브 시작 응답과 DB에 송출 키가 없다
- [x] 상세 화면의 "방송 종료"가 소유자에게만 보이고, 누르면 종료된다

- [x] 바꾼 테스트와 이유가 커밋 메시지에 있다
