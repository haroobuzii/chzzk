# 03: 상세 화면과 영상 재생

**What to build:** 시청자가 목록 카드를 누르면 `/broadcasts/{번호}` 상세 화면으로 간다. 위에 영상 재생기(`controls playsinline`)가 있고, 아래에 제목과 등록 시각, 목록으로 돌아가는 링크가 있다. 영상은 `GET /api/broadcasts/{번호}/video`에서 원본 그대로 받는다(ADR 0001). Range 요청을 지원하므로 끝까지 내려받지 않고 중간으로 건너뛸 수 있고, iOS Safari에서도 재생된다. 주소의 번호가 규칙에 맞지 않거나 없는 방송이면 404와 함께 "방송을 찾을 수 없습니다"와 목록 링크를 보여 준다. 번호 규칙은 ASCII 숫자만, 앞자리 0 없음, 1 이상, i64 범위다. 등록이 끝나면 이제 상세 화면으로 이동한다.

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 카드를 누르면 상세 화면이 나오고 영상이 재생된다. 상세 링크를 새 창에서 열어도 같은 방송이 나온다
- [x] 영상 요청에 Range가 있으면 206, `Content-Range`, `Accept-Ranges`와 정확한 바이트 범위가 온다. Range가 없으면 200과 전체 파일이 온다. `Content-Type`은 `video/mp4`다
- [x] 없는 번호, `0`, `01`, `abc`, 너무 큰 수로 상세나 영상을 요청하면 404다
- [x] 등록에 성공하면 새 방송의 상세 화면으로 이동한다
- [x] 자동 테스트: Range 응답, Range 없는 응답, 없는 번호 404, 같은 DB에 새로 연결해도(재시작 시나리오) 방송과 영상이 조회된다
