# 05: 업로드 진행률과 중복 클릭 막기

**What to build:** 큰 파일을 올리는 동안 방문자가 등록 화면에서 진행률(%)을 보고, 등록 버튼은 다시 눌리지 않는다. 진행률은 XMLHttpRequest의 업로드 진행 이벤트를 `document::eval` 채널로 Dioxus 쪽에 보내 표시한다. 업로드가 끝나거나 실패하면 버튼이 다시 살아나고, 실패했으면 이유가 보인다.

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 큰 파일을 올리면 진행률이 0%에서 100%까지 바뀌며 보인다
- [x] 업로드 중에는 등록 버튼과 입력이 막혀서 같은 방송이 두 번 생기지 않는다
- [x] 업로드가 실패하면 버튼이 다시 눌리고 실패 이유가 보인다
