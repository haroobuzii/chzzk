# 06: README 작성과 GitHub 제출 준비

**What to build:** 채점자가 README만 읽고 이 저장소를 이해하고 실행할 수 있다. 1단계 시점의 코드가 `step-1` 태그로 공개 GitHub 저장소 `haroobuzii/chzzk`에 고정된다. 채점은 소스와 README를 읽기만 하므로 README에 필요한 항목이 빠짐없이 있어야 한다. 실제 비밀 값은 저장소에 두지 않는다.

**Blocked by:** 03, 04, 05

**Status:** ready-for-agent

- [ ] README에 아래 항목이 있다.
  - 요구 환경: Rust, Dioxus CLI 0.7, Docker
  - 설치와 실행 명령
  - 환경변수 표와 예시
  - 1단계 구현 범위와 범위 밖 항목
  - 구성 설명
- [ ] README에 직접 확인 절차가 있다. 순서는 등록 → 목록 → 상세 → 재생과 건너뛰기 → 서버 재시작 → 다시 조회다. 실제 재생 확인용 작은 샘플 MP4를 구하는 방법도 적는다
- [ ] README에 선택 확인 절차가 있다. 같은 와이파이의 휴대폰으로 컴퓨터 주소에 접속해 등록과 재생을 해 본다
- [ ] README에 테스트 실행 방법과 실제 실행 결과(통과 개수)가 있다
- [ ] 저장소에 비밀 값이 없다. `.env`와 보관 폴더는 git에서 제외되어 있다
- [ ] 공개 저장소 `haroobuzii/chzzk`에 올리고 `step-1` 태그를 붙인다. 제출 주소는 `tree/step-1`이다
